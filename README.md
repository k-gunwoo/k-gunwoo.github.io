# Gunwoo Kim

One-page academic website for Gunwoo Kim, a graduate researcher at the
KAIST School of Computing and the IBS Discrete Mathematics Group.

## Local development

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
```

The profile content was compiled from public records maintained by IBS DIMAG,
conference organizers, arXiv, and Schloss Dagstuhl. The profile photograph is
from the public IBS DIMAG members page.
